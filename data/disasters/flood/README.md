# GISTDA Flood Data for Nakhon Pathom

ข้อมูลพื้นที่น้ำท่วมขังจากดาวเทียม โดย **สำนักงานพัฒนาเทคโนโลยีอวกาศและภูมิสารสนเทศ (องค์การมหาชน) - GISTDA**
คัดกรองเฉพาะพื้นที่ **จังหวัดนครปฐม (รหัส 73)** เพื่อสนับสนุนการเฝ้าระวังและการบริหารจัดการน้ำท่วมด้านการเกษตร

## แหล่งข้อมูล (Source)
- **แพลตฟอร์ม**: GISTDA Disaster Platform ([disaster.gistda.or.th](https://disaster.gistda.or.th))
- **เทคโนโลยีดาวเทียม**: Sentinel-1 SAR, Radarsat-2, Cosmo-SkyMed
- **การประมวลผล**: กรองและหักลบแหล่งน้ำถาวร (บ่อปลา, สระน้ำ, แม่น้ำ) ออกเรียบร้อยแล้ว คงเหลือเฉพาะพื้นที่น้ำท่วมขังจริง

## ไฟล์ข้อมูลในโฟลเดอร์นี้
1. `gistda-flood-summary.json`
   - สรุปตัวเลขสถิติพื้นที่น้ำท่วมแยกตามช่วงเวลา (1 วัน, 3 วัน, 7 วัน, 30 วัน)
   - สรุปยอดแยกรายอำเภอ (7 อำเภอ) และรายตำบล
   - ตัวเลขผลกระทบ: พื้นที่น้ำท่วม (ไร่), พื้นที่นาข้าว (ไร่), ประชากรที่กระทบ (คน), อาคาร/บ้านเรือน (หลัง), ความยาวถนน (กม.)
2. `gistda-flood-7days.geojson`
   - ขอบเขตเรขาคณิต (Polygon) ของพื้นที่น้ำท่วมในรอบ 7 วันล่าสุดของ จ.นครปฐม
   - พร้อมข้อมูลคุณลักษณะ (Properties) ประจำแต่ละแปลง
