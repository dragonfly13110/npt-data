# NPT Data (Static Hosting)

ศูนย์จัดเก็บข้อมูล Static Data และ GeoJSON สำหรับ **Nakhon Pathom Agricultural Dashboard** ผ่าน **GitHub Pages**:
`https://dragonfly13110.github.io/npt-data/`

## เอกสารอ้างอิง

- [หลักเกณฑ์ช่วยเหลือผู้ประสบภัยพิบัติด้านการเกษตร พ.ศ. 2569 (PDF ต้นฉบับ)](./documents/disaster-assistance-criteria-2569.pdf)
  ใช้กับภัยที่เกิดตั้งแต่วันที่ 21 สิงหาคม 2569 เป็นต้นไป
- [หลักเกณฑ์การใช้จ่ายเงินทดรองราชการเพื่อช่วยเหลือผู้ประสบภัย พ.ศ. 2569 (PDF)](./documents/emergency-disaster-advance-criteria-2569.pdf)
  ใช้กับภัยที่เกิดตั้งแต่วันที่ 6 มีนาคม 2569 เป็นต้นไป
- [คู่มือการให้ความช่วยเหลือเกษตรกร พ.ศ. 2565 (PDF)](./documents/farmer-assistance-manual-2565.pdf)
  คู่มือฉบับเดิม ใช้อ่านบทบาทและขั้นตอนอ้างอิง โดยตรวจหลักเกณฑ์และแบบฟอร์มปัจจุบันก่อนปฏิบัติงาน
