# NPT Data (Static Hosting)

## สรุปประจำวัน

รันเวลาไทย 09:17, 12:17 และ 17:17 น. ฉบับที่ AI ผ่านการตรวจสอบใช้ `generationMethod: ai` ถ้า AI ไม่พร้อมหรือข้อความไม่ผ่าน ใช้ฉบับสำรอง `source-summary` จากข้อมูลต้นทางที่ตรวจสอบแล้ว ถ้าไม่มีชุดข้อมูลที่ผ่านการตรวจสอบ ออก `source-unavailable` เพื่อแจ้งสถานะแทนการใส่ตัวเลข

วันสร้างฉบับและวันข้อมูลต้นทางเก็บแยกกัน การใช้สำเนาเดิมยังคงวันและ hash เดิม วันที่จัดทำย้อนหลังระบุ `backfilled: true` และเก็บเวลาสร้างจริง การสร้างย้อนหลังไม่เลื่อน `latest.json` กลับไปวันเก่า รอบถัดไปสามารถแทนฉบับสำรองด้วยสรุป AI ที่ผ่านการตรวจสอบได้

ศูนย์จัดเก็บข้อมูล Static Data และ GeoJSON สำหรับ **Nakhon Pathom Agricultural Dashboard** ผ่าน **GitHub Pages**:
`https://dragonfly13110.github.io/npt-data/`
